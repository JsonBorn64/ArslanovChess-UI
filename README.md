# ArslanovChess UI

Browser extension that adds "Analyze on ArslanovChess" buttons to **finished** games on Lichess, Endgame and other popular chess sites.

- The extension contains no chess engine and gives no hints: the buttons appear only after the game is over, and games without a result are rejected.
- Games are loaded only through official public APIs, which contain only finished games. Games with bots are not supported where the public API does not provide them.
